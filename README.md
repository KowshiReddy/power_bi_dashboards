# Power BI Dashboard Repository

![Power BI Dashboard Repository](https://www.biconnector.com/blog/wp-content/uploads/2020/03/Power-BI-Reduce-Visuals-and-Filters-1024x736.png)
 
Welcome to the **Power BI Dashboard Repository**, a collection of interactive Power BI projects designed to analyze and visualize diverse datasets effectively.  

## Available Dashboards  

1. **Customer Analysis Dashboard** – Insights into customer demographics, behavior, and purchasing patterns.
2. **E-commerce Sales Analysis Dashboard** – Tracks sales performance, revenue trends, and key metrics for online businesses.
3. **Happiness Report Dashboard** – Visualizes global happiness index data with key influencing factors.  
4. **Live Responsive Analysis Dashboard** – Displays real-time data updates with interactive visualizations. 
5. **Medicine Dashboard** – Analyzes medication usage, effectiveness, and prescription trends.  
6. **Sample Store Analysis Dashboard** – Provides an overview of store performance, sales, and inventory.  
7. **Sleep Analysis Dashboard** – Examines sleep patterns, duration, and quality for health insights.

## Repository Structure  

Each Power BI project is organized as follows:  

- **`project_name.pbix`** – Power BI report file.  
- **`data.csv` / `data.xlsx`** – Dataset used for analysis.  
- **`presentation.pptx`** (if available) – Summary of key insights.  

##  How to Use  

1. Clone the repository:  
   ```bash
   git clone https://github.com/KowshiReddy/power_bi_dashboards.git

   ```  
2. Open the `.pbix` file in Power BI Desktop.  
3. Explore the dashboards and gain insights from the data.
